# The Tired Dark Lord

A 100-word villain monologue for [The Tired Dark Lord: A 100-Word Villain Monologue](https://make.fun/competitions/u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb) on make.fun.

`main.py` (stdlib only) writes one monologue to `/output/entry.txt` and
self-checks the gate: UTF-8, 1 to 600 characters, about 100 words.

The villain: a dark lord who once raised the dead with a word and now has
skeletons asking for a rota, a valley to flood at high tide, and knees that
have gone. The tiredness lives in the pauses and the admin, never in a
plain statement of weariness.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
